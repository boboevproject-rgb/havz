## В одном абзаце

daoho.dev — личный сайт **Dao Ho**, инженера-программиста и студента Северо-Восточного университета (Northeastern University, Бостон, США). Главная страница — полноэкранный, не прокручиваемый **пруд с карпами кои, нарисованный текстовыми символами на canvas**: рыбы плавают вокруг вступительного текста, следуют за курсором, а если кликнуть по пустой воде, в неё падает гранула корма, и рыбы наперегонки плывут её съесть. Вокруг этого центра сайт держит пять продуктовых проектов с отдельными страницами-кейсами, галерею из семи премированных акварелей и блог, где пока написано «coming soon».

## Что есть на сайте

В верхней навигации четыре пункта: **pond · projects · gallery · blog** («пруд · проекты · галерея · блог») и переключатель темы с иконкой солнца/луны. На телефонах навигация сворачивается в плавающую «пилюлю».

### Pond — главная страница (`/`)

- Один экран, без прокрутки и без «резинового» перетягивания. За текстом лежит `<canvas>`, на котором собственный движок рисует кои **моноширинными символами** (вид ASCII-арта), с тенями, кильватерным следом, кругами на воде и вспышками укусов.
- Три породы кои генерируются случайно с разными весами: **кохаку, санке, танчо**. У каждой рыбы «позвоночник» из 20 узлов; она плывёт рывками ударов хвоста и затем скользит, ныряет и всплывает, пошевеливает грудными плавниками, когда зависает, проявляет любопытство к курсору, пугается и убегает при резком движении указателя и обходит текстовые блоки (элементы с атрибутом `data-koi-avoid`), бледнея, когда проплывает под ними.
- **Клик по пустой воде — кормление.** Гранула мгновение падает, приводняется, дрейфует; ближайшие кои «бросаются» к ней, открывают рот на подходе, и короткая вспышка отмечает укус. Клики по ссылкам, кнопкам и выделенному тексту игнорируются. Каждое кормление уходит в аналитику событием `koi_pond_fed`.
- Крошечный счётчик в правом верхнем углу показывает число рыб и число гранул на воде; число гранул мигает при изменении.
- Если ОС просит уменьшить анимацию, пруд даёт рыбам разойтись и замирает на одном кадре.
- Тексты набраны строчными моноширинным шрифтом: двустрочная цитата *«in an ocean of gluttony, / cast a fine net»* («в океане обжорства закинь тонкую сеть») с мигающим курсором, затем *«Xin chào, I'm Dao.»* («xin chào» — «привет» по-вьетнамски) и три предложения о Google, Agency, стартапах, Generate и PARCS Lab.
- Каждое название компании — **сноска-цитата**: при наведении открывается карточка с логотипом, должностью, датами и однострочным описанием; клик открывает сайт компании. Групповая сноска («early-stage startups») перечисляет DesignAI и Paynalli вместе. На сенсорных экранах названия просто ведут по ссылке.
- Внизу соцсети: github / linkedin / x.

### Мелкие части в коде

- **Секция опыта**, где логотип каждого работодателя отрисован интерактивным полем точек (по JSON-«картам логотипов») с текстом, проявляющимся при прокрутке.
- **График контрибуций GitHub**, который питает API-роут: он запрашивает GraphQL API GitHub и кэширует ответ в Redis на час.
- **Генератор карт логотипов** (`/generate-logo`) — страница-инструмент, которой из картинок делают те самые точечные карты.
- Общие UI-компоненты: док, анимированный список, круговой текст, «диск радиуса», стеклянная поверхность, scroll-reveal, view transitions.

## Как сделано

- **Фреймворк:** Next.js 14 (App Router), React 18, TypeScript. Развёрнуто на **Vercel** (сайт раздаётся с edge-сети Vercel; ответы приходили из региона `fra1`).
- **Стили:** Tailwind CSS 3 с `tailwindcss-animate` и `tailwind-scrollbar-hide`; утилиты в стиле shadcn (`class-variance-authority`, `clsx`, `tailwind-merge`); примитивы Radix UI (slot, switch); Material Tailwind; иконки Phosphor и Lucide.
- **Анимация:** Framer Motion и Motion для переходов интерфейса; GSAP со ScrollTrigger для скролл-эффектов; Swiper и `react-fast-marquee` для лент; `react-scroll`.
- **Пруд:** написан вручную, без игрового движка. `world.ts` — симуляция (кои, гранулы, укусы, круги, указатель, зоны обхода), `renderer.ts` рисует символы на 2D-canvas, `koi-pond.tsx` крутит цикл с фиксированным шагом 60 Гц и потолком в 4 шага за кадр, каждые 30 кадров заново измеряет текстовые блоки, чтобы следовать за сдвигами макета, останавливается вне экрана и уважает `prefers-reduced-motion`.
- **Типографика:** Geist Sans и Geist Mono лежат локально; Inter, Bebas Neue, Libre Baskerville, Roboto, Roboto Condensed, Oswald, Source Sans 3 и Playfair Display подключены через `next/font`.
- **Изображения:** `next/image` с выдачей AVIF/WebP и кэшем на 31 день; рецепт `just webp` конвертирует PNG-экспорты из Figma в WebP через `sharp`.
- **Аналитика:** PostHog (события и запись сессий), проксируется через rewrites `/ingest/*` на собственный домен, чтобы блокировщики рекламы не резали события; плюс Vercel Analytics.
- **Данные:** Redis (клиент `redis`) для кэша контрибуций; GraphQL API GitHub; переменные окружения `NEXT_PUBLIC_POSTHOG_PROJECT_TOKEN`, `GITHUB_TOKEN`, `REDIS_URL`.
- **Инструменты:** ESLint + Prettier; `justfile` с командами `install / dev / build / start / lint / format / typecheck / check / fix / clean / webp`; CI перед сборкой гоняет `just check` (линт, проверка форматирования, проверка типов).

## Язык дизайна

- Тёплая приглушённая палитра: светлая тема — фон `#f5f4f1`, текст `#262523`; тёмная — фон `#1a1917`, текст `#fff7f0`. Второстепенный текст — тот же цвет с прозрачностью 50–64 % через `color-mix`.
- Строчный моноширинный текст 13–15 px, щедрый интерлиньяж, колонка текста на десктопе выровнена по 20 vw.
- Повторяющиеся мотивы: мигающий курсор, тонкие подчёркивания, темнеющие при наведении, карточки-сноски и контент, который рыбы обходят, а не перекрывают.
- По умолчанию всё тихо и реагирует на посетителя (наведение, клик, прокрутка), а не крутится само.

## Про лицензию

В репозитории **нет файла лицензии**. По умолчанию на GitHub это значит, что все права остаются у автора: код можно читать и изучать, но нельзя копировать, менять и выкладывать как свой сайт без разрешения автора. Идеи — живой фон, обходящий текст, сноски-цитаты вместо резюме, салонная развеска галереи — свободны для изучения.
