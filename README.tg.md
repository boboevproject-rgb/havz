## Дар як сархат

daoho.dev — сомонаи шахсии **Dao Ho**, муҳандиси барномасоз ва донишҷӯи Донишгоҳи Northeastern (Бостон, ИМА). Тавсифи сомона дар метатегҳо ду калима аст: *«expression of self»* («ифодаи худ»). Ин портфолиои қолибӣ нест. Саҳифаи асосӣ — **ҳавзи моҳиҳои кои, ки бо аломатҳои матнӣ дар canvas кашида шудааст**, дар як экрани пурра ва бе скролл: моҳиҳо дар атрофи матни муаррифӣ шино мекунанд, аз паси курсор мераванд ва агар ба оби холӣ зер кунед, донаи хӯрок ба об меафтад ва моҳиҳо барои хӯрдани он мусобиқа мекунанд. Дар атрофи ин маркази сомона панҷ лоиҳаи маҳсулотӣ бо саҳифаҳои алоҳида, галереяи ҳафт расми обрангии ҷоизадор ва блоге ҳаст, ки ҳоло «coming soon» мегӯяд.

## Дар сомона чӣ ҳаст

Дар навигатсияи боло чор банд ҳаст: **pond · projects · gallery · blog** («ҳавз · лоиҳаҳо · галерея · блог») ва гузариши мавзӯъ бо нишонаи офтоб/моҳ. Дар телефон навигатсия ба як «ҳаб»-и шинокунанда печида мешавад.

### Pond — саҳифаи асосӣ (`/`)

- Як экран, бе скролл ва бе кашиши «резинӣ». Дар паси матн `<canvas>` ҳаст, ки дар он муҳаррики худӣ моҳиҳои коиро бо **аломатҳои моноширина** (намуди ASCII-арт) мекашад: бо сояҳо, изи дум, ҳалқаҳо дар об ва дурахши газидан.
- Се зоти кои бо вазнҳои гуногун тасодуфан сохта мешаванд: **кохаку, санке, танчо**. Ҳар моҳӣ «сутунмӯҳра»-и 20-нуқта дорад; бо зарбаҳои дум ба пеш ҷаҳида, баъд оҳиста мелағжад, ғӯта мезанад ва боло мебарояд, ҳангоми истодан бо қаноти сина оҳиста ҳаракат мекунад, ба курсор кунҷкобӣ мекунад, аз ҳаракати тези нишондиҳанда метарсад ва мегурезад ва аз блокҳои матн (элементҳо бо атрибути `data-koi-avoid`) канора мегирад ва вақте аз зери онҳо мегузарад, хира мешавад.
- **Зер кардан ба оби холӣ — хӯрок додан.** Дона як лаҳза меафтад, ба об мерасад, шино мекунад; моҳиҳои наздик ба сӯи он «медаванд», наздик шуда даҳон мекушоянд ва дурахши кӯтоҳ газиданро нишон медиҳад. Зер кардан ба пайвандҳо, тугмаҳо ё матни ҷудошуда ба назар гирифта намешавад. Ҳар хӯрокдиҳӣ ба аналитика ҳамчун рӯйдоди `koi_pond_fed` меравад.
- Ҳисобкунаки хурд дар кунҷи болои рост шумораи моҳиҳо ва донаҳои рӯи обро нишон медиҳад; шумораи донаҳо ҳангоми тағйир милт-милт мекунад.
- Агар система кам кардани ҳаракатро талаб кунад, ҳавз ба моҳиҳо имкон медиҳад пароканда шаванд ва баъд дар як кадри беҳаракат меистад.
- Матнҳо бо ҳарфҳои хурд ва шрифти моноширина: иқтибоси дусатра *«in an ocean of gluttony, / cast a fine net»* («дар уқёнуси пурхӯрӣ тӯри нозук андоз») бо курсори милт-милткунанда, баъд *«Xin chào, I'm Dao.»* («xin chào» ба ветнамӣ «салом» аст) ва се ҷумла дар бораи Google, Agency, стартапҳо, Generate ва PARCS Lab.
- Ҳар номи ширкат — **иқтибоси ҳошиявӣ**: ҳангоми гузаронидани курсор корти хурд бо логотип, вазифа, санаҳо ва тавсифи яксатра кушода мешавад; зер кардан сомонаи ширкатро мекушояд. Иқтибоси гурӯҳӣ («early-stage startups») DesignAI ва Paynalli-ро якҷоя номбар мекунад. Дар экранҳои ламсӣ номҳо танҳо пайванд мешаванд.
- Дар поён шабакаҳои иҷтимоӣ: github / linkedin / x.

### Қисмҳои хурд дар код

- **Бахши таҷриба**, ки дар он логотипи ҳар корфармо ҳамчун майдони интерактивии нуқтаҳо (аз рӯи JSON-«харитаҳои логотип») бо матни ҳангоми скролл пайдошаванда кашида мешавад.
- **Графики контрибутсияҳои GitHub**, ки аз API-роут ғизо мегирад: он GraphQL API-и GitHub-ро мепурсад ва ҷавобро як соат дар Redis нигоҳ медорад.
- **Генератори харитаҳои логотип** (`/generate-logo`) — саҳифаи асбоб, ки аз тасвирҳо ҳамон харитаҳои нуқтагиро месозад.
- Компонентҳои умумии UI: док, рӯйхати аниматсионӣ, матни даврӣ, «диски радиус», сатҳи шишагӣ, scroll-reveal, view transitions.

## Чӣ гуна сохта шудааст

- **Фреймворк:** Next.js 14 (App Router), React 18, TypeScript. Дар **Vercel** ҷойгир шудааст (сомона аз шабакаи edge-и Vercel дода мешавад; ҷавобҳо аз минтақаи `fra1` меомаданд).
- **Услубҳо:** Tailwind CSS 3 бо `tailwindcss-animate` ва `tailwind-scrollbar-hide`; утилитаҳо ба услуби shadcn (`class-variance-authority`, `clsx`, `tailwind-merge`); примитивҳои Radix UI (slot, switch); Material Tailwind; нишонаҳои Phosphor ва Lucide.
- **Аниматсия:** Framer Motion ва Motion барои гузаришҳои интерфейс; GSAP бо ScrollTrigger барои эффектҳои скролл; Swiper ва `react-fast-marquee` барои наворҳо; `react-scroll`.
- **Ҳавз:** дастӣ навишта шудааст, бе муҳаррики бозӣ. `world.ts` — симулятсия (кои, донаҳо, газиданҳо, ҳалқаҳо, нишондиҳанда, минтақаҳои канорагирӣ), `renderer.ts` аломатҳоро дар canvas-и 2D мекашад, `koi-pond.tsx` давраро бо қадами собити 60 Гс ва ҳадди 4 қадам дар як кадр мегардонад, ҳар 30 кадр блокҳои матнро аз нав чен мекунад, то аз паси тағйири макет равад, берун аз экран меистад ва `prefers-reduced-motion`-ро эҳтиром мекунад.
- **Типографика:** Geist Sans ва Geist Mono маҳаллӣ ҷойгиранд; Inter, Bebas Neue, Libre Baskerville, Roboto, Roboto Condensed, Oswald, Source Sans 3 ва Playfair Display тавассути `next/font` пайваст шудаанд.
- **Тасвирҳо:** `next/image` бо баромади AVIF/WebP ва кеши 31-рӯза; ретсепти `just webp` экспортҳои PNG-и Figma-ро тавассути `sharp` ба WebP табдил медиҳад.
- **Аналитика:** PostHog (рӯйдодҳо ва сабти сессияҳо), тавассути rewrites-и `/ingest/*` ба домени худӣ проксӣ мешавад, то блокаторҳои реклама рӯйдодҳоро набуранд; инчунин Vercel Analytics.
- **Маълумот:** Redis (клиенти `redis`) барои кеши контрибутсияҳо; GraphQL API-и GitHub; тағйирёбандаҳои муҳит `NEXT_PUBLIC_POSTHOG_PROJECT_TOKEN`, `GITHUB_TOKEN`, `REDIS_URL`.
- **Асбобҳо:** ESLint + Prettier; `justfile` бо фармонҳои `install / dev / build / start / lint / format / typecheck / check / fix / clean / webp`; CI пеш аз сохтан `just check`-ро иҷро мекунад (линт, санҷиши формат, санҷиши типҳо).

## Забони дизайн

- Палитраи гарми хомӯш: мавзӯи равшан — замина `#f5f4f1`, матн `#262523`; мавзӯи торик — замина `#1a1917`, матн `#fff7f0`. Матни дуюмдараҷа — ҳамон ранг бо шаффофияти 50–64 % тавассути `color-mix`.
- Матни ҳарфҳои хурди моноширина 13–15 px, фосилаи васеи сатрҳо, сутуни матн дар десктоп ба 20 vw баробар карда шудааст.
- Мотивҳои такроршаванда: курсори милт-милткунанда, зерхатҳои тунук, ки ҳангоми гузаронидани курсор торик мешаванд, кортҳои ҳошиявӣ ва мундариҷае, ки моҳиҳо аз он канора мегиранд, на онро мепӯшонанд.
- Ҳама чиз аз рӯи пешфарз ором аст ва ба меҳмон (гузаронидани курсор, зер кардан, скролл) ҷавоб медиҳад, на худ ба худ мечархад.
