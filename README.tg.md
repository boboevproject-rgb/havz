## ✨ Чаро ин сомона диққатро ҷалб мекунад

- **Заминаи зинда, ки видео нест.** Моҳиҳои кои дар вақти воқеӣ бо TypeScript-и дастӣ навишташуда симулятсия ва кашида мешаванд: на муҳаррики бозӣ, на китобхонаи WebGL.
- **Моҳиҳоро хӯрондан мумкин аст.** Ба оби холӣ зер кунед — донаи хӯрок меафтад, моҳиҳои наздик ба сӯи он медаванд ва мегазанд. Одамон маҳз барои ҳамин дар саҳифа мемонанд.
- **Резюме дар шакли иқтибосҳои ҳошиявӣ.** Номҳои ширкатҳо дар муаррифӣ — иқтибосанд: курсорро гузаронед, вазифа, санаҳо ва тавсифи яксатраро мебинед; зер кунед, сомонаи ширкат кушода мешавад.
- **Дар паси зебоӣ кори воқеӣ ҳаст.** Панҷ саҳифаи кейс (барнома барои «notch»-и Mac, панели амалиёти меҳмонхона, платформаи байторӣ, краудфандинги амволи ғайриманқул, боти аризаҳои корӣ) ва галереяи расмҳои обрангӣ, ки *Best in Show*-ро дар Осорхонаи санъати Балтимор гирифтаанд.
- **Маҳорати ором дар ҳар ҷузъ.** Матни ҳарфҳои хурди моноширина, палитраи гарми дуранга, курсори милт-милткунанда ва моҳиҳое, ки аз болои матн не, балки дар атрофи он шино мекунанд.

> 26 октябри соли 2026 дар асоси сомонаи зинда ва коди кушоди он навишта шудааст. Ин шарҳи мустақил аст; муаллифи сомона ба он алоқае надорад.

## 🐟 Ҳавз — саҳифаи асосӣ

<img src="screenshots/pond-dark.png" alt="Мавзӯи торик: ҳафт ASCII-кои, иқтибоси «in an ocean of gluttony, cast a fine net» ва матни муаррифӣ" width="100%">

<sub>Кунҷи болои рост: ҳисобкунаки хурд 7 кои ва 0 донаи хӯрокро дар об нишон медиҳад.</sub>

**Чӣ дида мешавад.** Як экран, бе скролл. Canvas тамоми равзанаро пур мекунад ва моҳиҳои кои аз се зот (кохаку, санке, танчо) дар он шино мекунанд. Дар боло матн: иқтибоси дусатра бо курсори милт-милткунанда, *«Xin chào, I'm Dao.»* («xin chào» ба ветнамӣ «салом» аст), се ҷумла дар бораи кор ва се пайванд ба шабакаҳои иҷтимоӣ.

**Моҳиҳо чӣ мекунанд.** Ҳар кои «сутунмӯҳра»-и 20-нуқта дорад. Бо зарбаҳои дум ба пеш ҷаҳида, баъд оҳиста мелағжад, ғӯта мезанад ва боло мебарояд, ҳангоми истодан бо қаноти сина оҳиста ҳаракат мекунад, ба курсор кунҷкобӣ мекунад, аз ҳаракати тези нишондиҳанда метарсад ва мегурезад ва аз блокҳои матн канора гирифта, дар зери онҳо хира мешавад.

**Хӯрок додан.** Ба оби холӣ зер кунед. Дона як лаҳза меафтад, ба об мерасад ва шино мекунад. Моҳиҳои наздик ба сӯи он медаванд, наздик шуда даҳон мекушоянд ва дурахш газиданро нишон медиҳад. Зер кардан ба пайвандҳо, тугмаҳо ё матни ҷудошуда ба назар гирифта намешавад. Ҳар хӯрокдиҳӣ ҳамчун рӯйдоди `koi_pond_fed` сабт мешавад.

**Дастрасӣ.** Агар дар система *кам кардани ҳаракат* фаъол бошад, ҳавз ба моҳиҳо имкон медиҳад пароканда шаванд ва баъд дар як кадри беҳаракат меистад.

<sub>Мавзӯи равшан. Нишонаи моҳ дар навигатсия онро иваз мекунад; интихоб дар localStorage нигоҳ дошта мешавад.</sub>

## ⬇️ Боргирӣ кунед ва худатон ба кор андозед

**Ин шарҳ** (матн + скриншотҳо):

```bash
git clone https://github.com/boboevproject-rgb/daoho-portfolio-overview.git
```

ё танҳо [бойгонии ZIP](https://github.com/boboevproject-rgb/daoho-portfolio-overview/archive/refs/heads/main.zip).

**Сомонаи аслӣ**, то онро дар компютери худ ба кор андозед (Node 18.17+ лозим аст):

```bash
git clone https://github.com/Dao-Ho/portfolio.git
cd portfolio
npm ci
npm run dev
```

Баъд http://localhost:3000-ро кушоед. Ҳавз, лоиҳаҳо ва галерея умуман бе калидҳо кор мекунанд. Се тағйирёбандаи ихтиёрии муҳит дар `.env.local` имконоти иловагиро фаъол мекунанд: `NEXT_PUBLIC_POSTHOG_PROJECT_TOKEN` (аналитика), `GITHUB_TOKEN` ва `REDIS_URL` (графики контрибутсияҳо). Ба назар гиред: репозиторий тақрибан **410 МБ** вазн дорад, зеро асарҳои аслии PNG ва паки дохилии `Design-Portfolio.git`-ро нигоҳ медорад. Агар `just` насб бошад, `just dev`, `just check` ва `just webp in.png out.webp` низ дастрасанд.
